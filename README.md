### 🚀 Featured Projects

- **[GraphRAG Aero](https://github.com/ahmedshahrukhali/graphrag-aero)**  
  Multilingual question answering over 77k chunks of aviation safety reports (English, French, Chinese). Combines BGE-M3 dense retrieval in Qdrant with cross-encoder reranking, Neo4j graph entity expansion, and a LangGraph human-in-the-loop review agent backed by FastAPI and Gradio.

- **[Odoo ML Restock Forecast](https://github.com/ahmedshahrukhali/odoo-ml-forecast)**  
  Production Odoo 17 module training LightGBM regressors on historical sales order series and writing 7-day demand forecasts directly into native inventory reordering rules (`stock.warehouse.orderpoint`). Includes an interactive OWL dashboard embedded in Odoo Inventory.

- **[Hugging Face Cookbook Contribution](https://github.com/huggingface/cookbook)**  
  Contributed engineering fixes to the vision-language GRPO (Group Relative Policy Optimization) recipe for modern TRL: conversational chat templating, reward function alignment, and pinned stable dependencies.

- **[LaunchpadHero](https://github.com/ahmedshahrukhali/LaunchpadHero)**  
  A Guitar Hero-style rhythm game for physical Novation Launchpad MIDI controllers, converting real-time MIDI input streams into synchronized audio-visual gameplay.
